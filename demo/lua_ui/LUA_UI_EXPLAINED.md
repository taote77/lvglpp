# Lua 脚本如何创建 UI - 图解说明

## 🎯 核心概念

### 什么是 Lua 脚本？

Lua 脚本就是一个文本文件，里面写的是 Lua 代码。这些代码会被 C++ 程序读取和执行。

**类比：**
- C++ 代码 = 建筑师的蓝图（底层结构）
- Lua 脚本 = 室内设计师的布置图（具体布局）

## 🔍 详细步骤说明

### 步骤 1: C++ 程序启动

```cpp
// main.cpp
int main() {
    // 创建应用
    LuaUIApplication app;
    
    // 运行应用
    app.exec();
}
```

**作用：** 启动整个程序，准备显示窗口

---

### 步骤 2: 初始化 Lua 引擎

```cpp
// main.cpp - initApp() 函数
lua_bind_->initialize();
```

**内部做了什么：**
```cpp
// LvglLuaBind.cpp
void LvglLuaBind::initialize() {
    // 1. 创建 Lua 虚拟机
    lua_state_ = new sol::state();
    
    // 2. 加载 Lua 标准库（print, math, string 等）
    lua_state_->open_libraries();
    
    // 3. 注册我们的函数到 Lua
    // 让 Lua 能调用 create_text, create_button 等
    registerLuaAPI();
}
```

**作用：** 让 Lua 脚本能使用我们提供的函数

---

### 步骤 3: 创建根控件

```cpp
// main.cpp - initApp() 函数
root_item_ = new BaseItem(nullptr);
root_item_->setSize(800, 480);  // 设置窗口大小
root_item_->setBgColor(0x1a1a1a); // 设置背景色

// 把 root 传给 Lua
lua_bind_->setRootItem(root_item_);
```

**作用：** 创建一个 800x480 的容器，所有其他控件都放在这里面

**类比：** 就像在墙上贴一张 800x480 的白纸，准备在上面画画

---

### 步骤 4: 加载 Lua 脚本

```cpp
// main.cpp - initApp() 函数
lua_bind_->executeFile("very_simple_demo.lua");
```

**内部做了什么：**
```cpp
// LvglLuaBind.cpp
bool LvglLuaBind::executeFile(filename) {
    // 1. 读取文件内容
    std::ifstream file(filename);
    std::string script = 读取文件内容;
    
    // 2. 执行 Lua 代码
    lua_state_->script(script);
}
```

**作用：** 把 Lua 脚本文件的内容读出来，一行行执行

---

### 步骤 5: Lua 脚本执行（关键！）

这是最关键的部分！让我们逐行分析 Lua 脚本：

#### 第 1 行：创建文本

```lua
local my_text = lvgl.create_text("你好 Lua!", 0xFFFFFF, root)
```

**发生了什么：**

```
Lua 脚本                              C++ 代码
    │                                      │
    ├─ 调用 lvgl.create_text()  ─────►  调用 LvglLuaBind::registerLuaAPI() 中的函数
    │                                      │
    │                                      ▼
    │                                ┌─────────────────────────┐
    │                                │  创建 LvText 对象     │
    │                                │  new LvText(...)      │
    │                                └─────────────────────────┘
    │                                      │
    │                                      ▼
    │                              返回 shared_ptr<LvText>
    │                                      │
    ▼                                      ▼
  my_text 变量指向这个对象
```

**结果：** 内存中创建了一个 LvText 对象，my_text 变量指向它

---

#### 第 2 行：设置位置

```lua
my_text:set_pos(50, 50)
```

**发生了什么：**

```
my_text (Lua 变量)
    │
    ├─ 调用 set_pos()  ─────►  调用 C++ LvText::setPos(50, 50)
    │                           │
    │                           ▼
    │                    ┌─────────────────────────┐
    │                    │  lv_obj_set_pos()    │
    │                    │  LVGL C 函数         │
    │                    └─────────────────────────┘
    │                           │
    │                           ▼
    │                    文本移动到 (50, 50)
```

**结果：** 文本控件移动到屏幕坐标 (50, 50) 的位置

**类比：** 就像在纸上写字，把字写在 (50, 50) 的位置

---

#### 第 3 行：创建按钮

```lua
local my_button = lvgl.create_button(200, 60, "点击我", root)
```

**发生了什么：**

```
Lua 脚本                              C++ 代码
    │                                      │
    ├─ 调用 lvgl.create_button()  ──►  创建 PushButton 对象
    │                                      │
    │                                      ▼
    │                              ┌─────────────────────────┐
    │                              │  创建按钮背景         │
    │                              │  创建按钮文字         │
    │                              │  设置按钮样式         │
    │                              └─────────────────────────┘
    │                                      │
    ▼                                      ▼
  my_button 变量指向这个对象
```

**结果：** 创建了一个 200x60 大小的按钮，上面写着"点击我"

---

#### 第 4 行：设置按钮位置

```lua
my_button:set_pos(50, 150)
```

**结果：** 按钮移动到 (50, 150) 的位置

---

#### 第 5 行：添加点击事件

```lua
my_button:set_on_clicked(function()
    my_text:set_text("你点击了按钮！")
    lvgl.print("按钮被点击了！")
end)
```

**这是最有趣的部分！让我们分解：**

```
┌─────────────────────────────────────────────────────────────┐
│  第1步：定义一个 Lua 函数                      │
│  function()                                    │
│      my_text:set_text("你点击了按钮！")         │
│      lvgl.print("按钮被点击了！")               │
│  end                                          │
└─────────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  第2步：把这个函数传给 C++                      │
│  my_button:set_on_clicked(这个函数)              │
└─────────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  第3步：C++ 保存这个函数                          │
│  PushButton::setOnClickedListener([Lua函数]) {      │
│      // 当按钮被点击时，调用这个 Lua 函数      │
│  }                                             │
└─────────────────────────────────────────────────────────────┘
```

**类比：** 就像在按钮上贴一个便签，上面写着"点击后做什么"

## 🎨 创建 UI 的思维模型

### 方式 1：从左到右（推荐）

```
1. 创建根容器
   ↓
2. 创建第1个控件
   ↓
3. 设置第1个控件的位置
   ↓
4. 创建第2个控件
   ↓
5. 设置第2个控件的位置
   ↓
...继续...
```

### 方式 2：从上到下

```
1. 创建标题
   ↓
2. 创建副标题
   ↓
3. 创建按钮区
   ↓
4. 创建状态区
```

## 💡 关键要点

### 1. 变量管理

```lua
-- 创建控件后，用变量保存引用
local text = create_text(...)
local button = create_button(...)

-- 后续通过这个变量操作控件
text:set_text("新内容")
button:set_on_clicked(...)
```

**为什么需要变量？**
- 因为创建控件后，需要记住它
- 后续要修改它或给它添加事件

### 2. 父子关系

```lua
-- 所有控件都需要父容器
create_text(..., root)  -- root 是父容器
create_button(..., root) -- root 是父容器
```

**为什么需要父容器？**
- 就像文件夹和文件的关系
- 父容器决定子控件显示在哪里
- 父容器销毁时，子控件也会销毁

### 3. 事件驱动

```lua
-- 不主动检查，而是被动响应
button:set_on_clicked(function()
    -- 当事件发生时，自动执行
end)
```

**为什么这样设计？**
- 更高效（不需要一直检查）
- 更清晰（代码逻辑和事件处理分离）
- 更灵活（可以随时添加/移除事件）

## 🎓 实际应用示例

### 示例 1：登录界面

```lua
-- 创建标题
local title = create_text("用户登录", 0xFFFFFF, root)
title:set_pos(300, 50)

-- 创建用户名输入框（假设有这个控件）
local username = create_input(300, 40, root)
username:set_pos(250, 150)

-- 创建密码输入框
local password = create_input(300, 40, root)
password:set_pos(250, 220)

-- 创建登录按钮
local login_btn = create_button(150, 50, "登录", root)
login_btn:set_pos(325, 300)

-- 点击登录按钮
login_btn:set_on_clicked(function()
    local user = username:get_text()
    local pass = password:get_text()
    
    -- 验证用户名和密码
    if user == "admin" and pass == "123456" then
        title:set_text("登录成功！")
    else
        title:set_text("用户名或密码错误")
    end
end)
```

### 示例 2：计数器

```lua
-- 创建显示文本
local count_text = create_text("计数: 0", 0xFFFFFF, root)
count_text:set_pos(350, 100)

-- 创建计数变量
local count = 0

-- 创建增加按钮
local add_btn = create_button(100, 50, "+1", root)
add_btn:set_pos(200, 200)

-- 创建减少按钮
local sub_btn = create_button(100, 50, "-1", root)
sub_btn:set_pos(450, 200)

-- 增加按钮事件
add_btn:set_on_clicked(function()
    count = count + 1
    count_text:set_text("计数: " .. count)
end)

-- 减少按钮事件
sub_btn:set_on_clicked(function()
    count = count - 1
    count_text:set_text("计数: " .. count)
end)
```

## 🚀 总结

### Lua 脚本创建 UI 的本质

1. **声明式**：告诉程序"我想要什么"，而不是"怎么做"
2. **事件驱动**：响应动作，而不是主动检查
3. **动态性**：运行时创建和修改 UI，无需重新编译

### 优势

- ✅ 快速开发：修改 Lua 脚本即可，无需重新编译
- ✅ 易于学习：Lua 语法简单
- ✅ 灵活性：可以动态加载不同的 UI 脚本
- ✅ 分离关注点：UI 逻辑和业务逻辑分离

### 学习建议

1. **先看示例**：运行 very_simple_demo.lua，理解每一行
2. **修改示例**：改变文字、位置、颜色，看效果
3. **创建简单界面**：从 1-2 个控件开始
4. **逐步增加**：添加更多控件和事件
5. **参考文档**：查看 API 文档了解更多功能
